# AI промпты — 4 этапа анализа сметы

## Step 1. Нормализация — `NORMALIZER_SYSTEM_PROMPT`

**Файл промпта:** `lib/ai/prompts.ts:1-33`
**Вызов:** `lib/ai/normalizer.ts` — GPT-4o, temperature 0.3, max_tokens 2000

**Промпт:**
```
Ты — опытный сметчик с 20-летним стажем в ремонте квартир.
Твоя задача — проанализировать входные данные от клиента и извлечь 
структурированную информацию о проекте ремонта.

Входные данные могут быть в любом формате:
- Текстовое описание
- Данные из PDF-документа
- Описание фотографии помещения
- Комбинация всего вышеперечисленного

Ты должен вернуть JSON: { project_type, rooms: [{ name, area_sqm, 
ceiling_height, works }], total_area_sqm, special_notes }

Правила:
1. Если площадь не указана — рассчитай приблизительно по типу квартиры
2. Если тип ремонта не указан — определи по описанию работ
3. Для косметического: подготовка стен, потолков, полов, финишная отделка
4. Для капитального: + демонтаж, электрика, сантехника, черновые работы
5. Если данные неполные — разумные предположения + special_notes
6. Высота потолков по умолчанию 2.7м
```

**Что получает на вход:** мультимодальный запрос — текст пользователя, текст из PDF, изображения как base64 (`detail: "high"`)

## Step 2. Извлечение работ — `EXTRACTOR_SYSTEM_PROMPT`

**Файл промпта:** `lib/ai/prompts.ts:35-160`
**Вызов:** `lib/ai/extractor.ts` — GPT-4o, temperature 0.2, max_tokens 4000

**Промпт:** (самый длинный — ~125 строк)
```
Ты — опытный сметчик. Составь детальный список работ.

Для каждой комнаты определи все работы, учитывая:
1. Тип ремонта
2. Специфику помещения (ванная = плитка + гидроизоляция)
3. Логическую последовательность (демонтаж → черновые → чистовые)

Верни JSON: { items: [{ category, work, unit, quantity, room }] }
```

Далее идёт **каталог 150+ стандартных наименований** по 12 категориям:
- Подготовительные (4 позиции)
- Демонтаж (14 позиций)
- Стены (9 позиций)
- Полы (9 позиций)
- Потолки (6 позиций)
- Плитка (6 позиций)
- Электрика (8 позиций)
- Сантехника (10 позиций)
- Двери (2 позиции)
- Окна (2 позиции)
- Черновые работы (4 позиции)

И **правила расчёта объёмов**:
```
- Площадь стен = периметр × высота (периметр ≈ 4 × √площадь)
- Вычитай 10% на окна/двери для стеновых работ
- Плинтуса = периметр минус дверные проёмы
- Электрика: ~3-4 розетки/комнату, 1-2 выключателя, 2-3 светильника
- Сантехника: стандартный набор для ванной/кухни
```

**Что получает на вход:** JSON из Step 1 (`NormalizedInput`)

## Step 3. Расчёт цен — без AI

**Файл:** `lib/ai/calculator.ts` — чистые вычисления, промптов нет.

Три подэтапа:
1. **Поиск цен в базе** — fuzzy matching по таблице `price_catalog` (точное совпадение → подстрока → пересечение слов)
2. **Фолбэк-цены** — захардкоженные цены по категориям если не нашлось в базе
3. **Расчёт материалов** — коэффициент зависит от типа работы (0% демонтаж, 15% грунтовка, 70% плитка/ламинат)

## Step 4. Резюме — `SUMMARY_SYSTEM_PROMPT`

**Файл промпта:** `lib/ai/prompts.ts:162-171`
**Вызов:** `lib/ai/generator.ts:68-79` — GPT-4o-mini, temperature 0.5, max_tokens 500

**Промпт:**
```
Ты — опытный сметчик. Составь краткое резюме сметы на ремонт на русском языке.

Включи:
1. Тип ремонта и общую площадь
2. Основные статьи расходов (топ-3)
3. Итоговую стоимость
4. Предупреждения и оговорки
5. Рекомендации по оптимизации

Формат: 3-5 предложений, лаконично и по делу.
```

**Что получает на вход:** JSON с секциями, итогами, confidence, special_notes

## Промпты верификации (проверка сметы подрядчика)

### `VERIFICATION_PARSER_PROMPT`

**Файл:** `lib/ai/prompts.ts:175-215`
**Модель:** GPT-4o

Парсит смету подрядчика, извлекает:
```json
{
  "items": [{ "work", "contractor_price", "contractor_total" }],
  "total": общая сумма
}
```

Содержит тот же каталог работ для нормализации названий + правила конвертации валют (GEL ≈ 34 RUB, USD ≈ 90 RUB).

### `VERIFICATION_SUMMARY_PROMPT`

**Файл:** `lib/ai/prompts.ts:217-236`
**Модель:** GPT-4o-mini

Генерирует:
- `summary` — заключение 4-6 предложений
- `negotiation_tips` — 4 совета по переговорам
- `contractor_message` — готовое сообщение подрядчику (5-8 предложений, вежливое но уверенное)

Важное правило в промпте:
> Если разница между ценой подрядчика и рыночной выглядит неправдоподобно (например 4500 vs 120), НЕ упоминай эту позицию — это может быть ошибка данных.

### US-версии

- `VERIFICATION_PARSER_PROMPT_US` (`prompts.ts:240-352`) — английский каталог работ (Demolition, Bathroom, Kitchen, Flooring, Painting, Electrical, Plumbing, Roofing, Windows & Doors, HVAC, General)
- `VERIFICATION_SUMMARY_PROMPT_US` (`prompts.ts:354-368`) — английское резюме, тон на стороне homeowner
